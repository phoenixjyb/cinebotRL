# Riser Hardware Production Candidate V1

This CPU-only evidence replaces the vague `750 W class` production fallback
with one pinned 48 V supplier/bench design-review candidate:

- motor: Leadshine `ELVM8075V48EH-M17-HD`;
- drive: Leadshine `ELD2-CAN7020B`;
- transmission: `3:1` reduction and `70 mm/rev`;
- mechanism: supplier-qualified guided belt axis, or a supplier-qualified
  synchronized two-stage telescoping mast if collapsed height requires it.

The official motor and drive data support 750 W, 48 V, 2.39 N m rated torque,
7.17 N m peak torque, brake, absolute encoder, 20 Arms drive output, and an
official motor/drive match. Under the existing conservative 8 kg calculation,
the candidate provides `550.2589 N` rated equivalent linear force and a
`1.9868` emergency-force margin, above the project minimum `1.15`.

This is not production procurement approval. Complete moving mass, friction,
counterbalance, eccentric moments, vertical-axis duty, gearbox, regeneration,
anti-fall, limits, stopping, and thermal behavior remain unmeasured or
unselected. The report therefore keeps production procurement, hardware
transfer, simulation-model replacement, runtime, GPU work, and training false.

`summary.json` is generated by
`scripts/two_wheel_balance/audit_riser_hardware_production_candidate.py`.
The audit changes no robot asset, trajectory, controller, gate, authorization,
capture, dataset, or policy.
