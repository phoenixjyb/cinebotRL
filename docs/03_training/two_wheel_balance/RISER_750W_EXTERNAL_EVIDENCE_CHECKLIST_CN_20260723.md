# 750 W 升降轴外部证据采集清单

## 结论

当前已经完成候选电机、驱动器、传动参数和验收阈值的工程定义，但尚未完成供应商确认和实物台架验证。

- 候选电机：Leadshine `ELVM8075V48EH-M17-HD`
- 候选驱动器：Leadshine `ELD2-CAN7020B`
- 传动：`3:1`，等效导程 `0.07 m/rev`
- 相机软件高度范围：`0.60-1.80 m`
- 软件工作行程：`1.20 m`
- 机械行程下限：`1.50 m`
- 设计运动质量：`8 kg`
- 最高速度：`1.0 m/s`
- 连续垂直推力下限：`300 N`

机器可读清单位于：

`docs/03_training/two_wheel_balance/evidence_20260723_riser_750w_external_checklist_v1/summary.json`

该清单准备完成不代表硬件通过验收，也不授权采购、硬件移交、仿真电机模型切换、GPU 运行或训练。

## 必须采集的外部证据

供应商模板当前有 `52` 个缺失或无效字段。必须由供应商填写并签署，至少包括：

- 垂直移动轴型号、架构、减速器型号和完整传动参数；
- `1 m/s`、`8 kg`、连续垂直负载和占空比能力；
- 减速器连续转速、紧急制动力矩、效率和回程间隙；
- 同步带防跳齿余量；
- 再生能量吸收、电机抱闸静态保持、独立防坠和安全断能方案；
- 所有数据表、计算书、批准文件和签署响应的 SHA-256。

台架模板当前有 `34` 个缺失或无效字段。必须在完整实物装配和标定仪器上采集，至少包括：

- 完整运动质量、摩擦力、配重力和实际机械行程；
- 力、电流、温度和位置标定记录；
- `1800 s`、`60%` 占空比、`1 m/s` 连续运行数据；
- 电机和驱动器温升、热稳态斜率、电流和母线再生电压；
- 至少 `10` 次高速急停和最坏停止距离；
- 电机抱闸静态保持、独立防坠、上下硬限位、吸能端挡和安全断能测试；
- 原始日志、标定记录和安全测试视频的 SHA-256。

## 固定采集顺序

1. 取得签署的供应商响应、数据表和工程计算书，并运行供应商审计。
2. 装配完整的 `750 W` 垂直升降轴，包括独立防坠、硬限位、吸能端挡和安全断能。
3. 使用完成标定的仪器采集原始台架日志和人工安全证据。
4. 使用候选型号绑定的日志归约器生成数值证据。
5. 将供应商审计、数值归约和人工测量合并，运行最终台架门禁。

禁止跳过供应商审计直接填写 `supplier_evidence`，禁止手工填写自动归约字段，禁止用模板默认值或合成值替代实测数据。

```bash
python3 scripts/two_wheel_balance/build_riser_750w_external_evidence_checklist.py \

```
