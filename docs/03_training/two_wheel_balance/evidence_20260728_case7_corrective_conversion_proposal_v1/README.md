# Case-7 Corrective Conversion Proposal

This package binds one CPU-only conversion proposal to the sealed case-7 v2
corrective capture. The proposal reopens 6,597 samples, preserves the source,
execution, and elapsed clocks, uses effective post-supervisor residuals as
targets, and reconstructs previous-action observation channels.

The proposal does not authorize conversion by itself. It creates no converted
dataset, corpus, BC/PPO artifact, checkpoint, or training run.
